# Jaabe Site — فروشگاه جعبه جواهرات حک نگار

سامانه فارسی و واکنش‌گرای فروش عمده جعبه جواهرات برای طلافروشی‌ها، ساخته‌شده با React، FastAPI و SQLite.

## امکانات

- ویترین محصولات، دسته‌بندی، چند تصویر، قیمت بسته و کنترل موجودی
- سبد خرید، فاکتور، اطلاعات تماس و اطلاعات حکاکی
- ثبت لوگو یا کارت ویزیت مشتری
- پرداخت کامل، پرداخت هنگام تحویل ویژه بهبهان و بیعانه ۱۰ درصد
- پیگیری سفارش با کد سفارش و نمایش تاریخ تقریبی آماده‌شدن
- ورود پیامکی مدیران با SMS.ir و سطح دسترسی مدیر اصلی/ادمین
- مدیریت محصولات، دسته‌بندی‌ها، سفارش‌ها، فوتر و درخواست مراجعه ویزیتور
- بازوی بله برای مشاهده محصولات، ثبت و پیگیری سفارش و درخواست ویزیتور
- اعلان سفارش‌ها و درخواست‌های جدید در بله مدیر
- تاریخ و ساعت شمسی در پنل مدیریت

## فناوری‌ها

- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: SQLite
- پیامک: SMS.ir
- پیام‌رسان: Bale Bot API

## اجرای محلی

پیش‌نیازها: Python 3.11+ و Node.js 20+ یا pnpm.

در پنجره اول PowerShell:

```powershell
.\start-backend.ps1
```

در پنجره دوم:

```powershell
.\start-frontend.ps1
```

آدرس‌ها:

- فروشگاه: `http://127.0.0.1:5173`
- پنل مدیریت: `http://127.0.0.1:5173/admin`
- مستندات API: `http://127.0.0.1:8000/docs`

## ورود و راه‌اندازی اولیه

ورود اولیه توسعه:

- نام کاربری: `admin`
- رمز عبور: `admin123`

پس از ورود، در بخش «مدیران و پیامک» کلید API سرویس SMS.ir را ثبت و ورود پیامکی را فعال کنید. شماره مدیر اصلی به‌صورت پیش‌فرض `09399506609` است. پس از نخستین ارسال موفق پیامک، ورود ثابت غیرفعال می‌شود.

> پیش از انتشار عمومی، رمز ورود اولیه را تغییر دهید و HTTPS، محدودیت CORS، پشتیبان‌گیری دیتابیس و تنظیمات درگاه پرداخت را برای محیط تولید تکمیل کنید.

## اطلاعات محرمانه و داده‌ها

فایل SQLite، توکن‌های SMS.ir و بله، فایل‌های آپلودی مشتریان، خروجی build و `node_modules` عمداً در Git ذخیره نمی‌شوند. دیتابیس در نخستین اجرای بک‌اند ساخته می‌شود و تنظیمات محرمانه از طریق پنل مدیریت در همان دیتابیس محلی نگهداری می‌شوند.

## ساخت فرانت‌اند

```powershell
cd frontend
pnpm install
pnpm build
```

## به‌روزرسانی ظاهر روی هاست موجود

بازطراحی جدید فقط رابط کاربری را تغییر می‌دهد؛ تغییر ساختار دیتابیس یا اجرای migration لازم نیست. تاریخچه همراه این انتشار همچنین شامل اصلاح قبلی دامنه بازگشت زرین‌پال از `jaabehakenegar.ir` به `jaabehaknegar.ir` است؛ این اصلاح روی محصولات و موجودی اثر ندارد.

- برای هاست فعلی، پوشه `frontend/dist` را با خروجی جدید همین پوشه جایگزین کنید. مسیر سرو کردن فرانت‌اند و تنظیمات فعلی API را حفظ کنید؛ API در خروجی انتشار از همان دامنه سایت خوانده می‌شود.
- فایل دیتابیس فعال هاست (معمولاً `backend/shop.db` یا مسیر تعیین‌شده با `JAABE_DB_PATH`) و پوشه آپلودها (`backend/uploads` یا `JAABE_UPLOAD_DIR`) را حفظ کنید. دیتابیس محلی را روی هاست کپی نکنید و دیتابیس تازه نسازید.
- قبل از استقرار، از دیتابیس فعال و فایل‌های آپلودی هاست بکاپ بگیرید. اگر از استقرار خودکار استفاده می‌کنید، این مسیرها باید در فضای پایدار هاست و خارج از پوشه‌ای باشند که هنگام استقرار پاک می‌شود؛ مقادیر فعلی `JAABE_DATA_DIR`، `JAABE_DB_PATH` و `JAABE_UPLOAD_DIR` را تغییر ندهید.
- اطلاعات «درباره ما»، خدمات و تماس همچنان با `GET /api/settings` از دیتابیس خوانده می‌شوند. مدیر اصلی می‌تواند آن‌ها را در بخش تنظیمات فوتر پنل ادمین تغییر دهد؛ ذخیره با `PUT /api/admin/settings` انجام می‌شود. با بارگذاری دوباره صفحه، اطلاعات ذخیره‌شده نمایش داده می‌شوند.
- پس از آپلود، صفحه اصلی، `/order`، `/admin` و `/api/health` را بررسی کنید و نمایش محصولات، موجودی‌ها و اطلاعات تماس را با وضعیت قبل مقایسه کنید.
